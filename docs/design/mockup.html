Tokens (see DESIGN.md for full detail)

Fonts — sans: Inter (chrome) · serif: Newsreader (reading content) · hand: Caveat (wordmark + LockScreen, 1–2 spots).

Colors — stone-50 light bg · #000 AMOLED dark bg · amber-600 accent (decorative, light) · amber-700 accent text (light) · amber-500 accent (dark).

Where serif lives — page H1s, mind section titles, assistant chat bubbles (with leading-relaxed), insight body, latest-insight preview, diary excerpts in /notebooks (the most emotionally resonant change — handwritten content rendered as a printed journal page), memory profile textarea.

Where serif is not — all chrome (nav, buttons, badges, stat numbers, meta), all text-xs/text-[10px], cost calendar, Memory settings labels, theme cloud, entity rankings, user chat bubbles.

Focus — amber 2px :focus-visible ring (keyboard-only). Tap targets — 44px floor on touch, buttons only (not inline links). Motion — smooth scroll + prefers-reduced-motion guard.

Network posture — fonts are self-hosted at build via next/font/google. The browser never hits Google at runtime. This mockup file loads them via CDN for preview only.
