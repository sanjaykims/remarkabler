Engineering log only. This repo is **public**, so no personal locations,

## Requests and what happened (in order)

1. **Saved places feature removed.** The in-app "Saved places" (added earlier
   the same day, `7d1d957`) was reverted (`0e57149`, changelog `72529ae`). Named
   places now live in the owner's Supabase `saved_places` table, matched by
   Claude on request, so Remarkabler keeps no copy.
2. **New Map tab** (`feeed68`): `/map`, Leaflet + OpenStreetMap tiles, stays as
   dots, thinned route polyline, latest position, range buttons. Data from
   auth-gated `GET /api/map` (`mapData()` in `lib/owntracks.ts`, pure helpers in
   `lib/mapData.ts`); place names are cache-only (no Nominatim call on view).
   Not exposed over MCP.
3. **4-digit PIN in front of the Map** (`6caa3c0`): server-enforced
   (`/api/map` returns 403 without the signed `fc_map_unlock` cookie), scrypt-hashed
   PIN, escalating lockout (5 tries → 15 min → 1 h → 4 h → 24 h), re-locks when
   the page is left or backgrounded, forgot-PIN reset requires the app passcode,
   `map_pin_*` settings redacted from off-site backups. Scope: Map only.
4. **Trail coloured by time** (`8d113c0`): blue (earliest) → orange (latest) with a
   colour key; stay dots take the colour of arrival time.
5. **Bug: three lines for a one-round-trip day** (`1656206`). Cause: "Today" was a
   rolling 24 h window, so the previous evening's trip home was drawn too.
   Fix: ranges are calendar days from local midnight (`mapWindowStart`).
   Verified with seeded test data (Today → 2 lines, 2 days → 3 lines) and
   against the recorded stays via the MCP location tool.
6. **Graphify check:** confirmed (via the Graphify graph) that the rolling window
   is still used only by chat/debug/geocode-warm paths, intentionally.
